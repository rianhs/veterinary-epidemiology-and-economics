This glossary is the controlled vocabulary of the course. All content uses the terms in the "Term" column with the meaning given here. Terms in the "Do not use" column are synonyms that students meet in other sources. Mention them once in the relevant article so students recognize them, then use the course term.

Rows marked "course convention" are working choices for this course. Other sources can use the terms in a different way.

| Term | Definition | Do not use |
|-|-|-|
| Active surveillance | Surveillance in which the investigator decides which units to examine and collects the data | |
| Adjusted odds ratio | An odds ratio that accounts for one or more other factors, from stratified analysis or a regression model | |
| Analytical epidemiology | The approach that studies the determinants of health events by comparing groups | Analytic epidemiology |
| Animal-time | The sum of the time that each animal is at risk during the observation period, for example in animal-days or animal-years | Animal-time at risk (accepted in formulas) |
| Apparent prevalence | The proportion of tested animals with a positive test result. It includes false positives and misses false negatives | Test prevalence |
| Associated factor | A factor that is statistically associated with an outcome. Course convention | |
| Attack rate | The incidence risk during an outbreak, for a defined group and period. It is a proportion, despite its name | |
| Attributable fraction | The proportion of disease in exposed animals that is due to the exposure, if the association is causal | Attributable risk percent |
| Baseline | The expected level of disease or of reports in a population over a period. Used to detect unusual events | |
| Basic reproduction number (R0) | The average number of secondary cases that one infectious animal causes in a fully susceptible population | R-naught (mention once) |
| Benefit-cost ratio | The total benefits of an intervention divided by its total costs, both in money, for the same period and perspective | |
| Bias | A systematic error that moves an estimate away from the true value | |
| Case | A unit (animal, herd, or other) that meets the case definition | |
| Case definition | A set of criteria (animal, place, time, clinical signs, test results) that decides whether a unit counts as a case | |
| Case fatality | The proportion of cases that die of the disease within a stated period | Case fatality rate |
| Case-control study | An observational study that compares the past exposure of cases with that of non-cases | |
| Causal factor | A factor whose change changes the outcome, supported by causal appraisal. Course convention | |
| Census | Counting or examining every unit in a defined population | |
| Cluster sampling | A probability method that randomly selects groups (herds, villages) and examines all or some units in each group | |
| Cohort study | An observational study that follows exposed and unexposed groups over time and compares the occurrence of the outcome | |
| Compartmental model | A model that divides a population into groups by infection status and describes the flows between the groups | |
| Confidence interval | A range, calculated from sample data, that is likely to include the true population value at a stated level, often 95% | |
| Confidence of freedom | The probability that a population is free of disease, or has prevalence below the design prevalence, given negative surveillance results | |
| Confounding | A distortion of an association by a third factor that is related to both the exposure and the outcome | |
| Cost-effectiveness | The cost of an intervention per unit of health effect, for example cost per case averted | |
| Cross-sectional study | An observational study that measures exposure and outcome in a population at one point in time | Prevalence study (mention once) |
| Crude odds ratio | An odds ratio calculated from one two-by-two table, without accounting for other factors | Unadjusted odds ratio |
| Decision maker | The person or body that chooses between actions on a health problem, for example a farm owner, a company, or a government authority. Course convention | |
| Denominator | The number of units, or the animal-time, that a count is divided by | |
| Descriptive epidemiology | The approach that describes the distribution of health events by animal, place, and time | |
| Design effect | The factor by which cluster sampling increases the sample size needed, compared with simple random sampling | |
| Design prevalence | The prevalence that a survey must be able to detect if disease is present. It is a planning value. Surveys do not estimate it | Minimum expected prevalence |
| Determinant | Any factor that changes the frequency of a health event in a population | |
| Discounting | Reducing future costs and benefits to their present value, so that amounts in different years can be compared | |
| Effect modification | A situation in which the size of an association differs between levels of a third factor | Interaction (mention once) |
| Effective reproduction number (Re) | The average number of secondary cases that one infectious animal causes at a given time, in the actual population with its immunity and control measures | Rt |
| Elimination | The removal of a disease from a defined area, so that no cases occur there. Measures continue to prevent reintroduction | Eradication (for a single country or area) |
| Endemic | Describes a disease that is constantly present in a population at an expected level | Enzootic |
| Epidemic | Describes the occurrence of a disease clearly above the expected level in a wider area or population | Epizootic |
| Epidemic curve | A graph of the number of new cases by time of onset | Epicurve |
| Epidemiological triangle | A model of disease as the result of interaction between agent, host, and environment | Epidemiologic triad |
| Epidemiological unit | A group of animals that share about the same likelihood of exposure to an agent, for example because they share a pen or management. Usually a herd or flock (WOAH) | |
| Epidemiology | The study of the distribution and determinants of health-related states or events in specified populations, and the application of this study to the control of health problems (Last, 2001) | |
| Experimental epidemiology | The approach that studies determinants or interventions in trials, in which the investigator assigns the exposure | Intervention study (mention once) |
| Exposure | A factor that an animal has or is in contact with, whose effect on an outcome is studied | |
| Externality | An effect of an action on people who do not take part in the decision, for example disease spread from one farm to its neighbours | Spillover effect (in economics) |
| Freedom from disease | The status of a population in which a disease is absent, shown by evidence at a stated design prevalence and confidence | Disease freedom |
| Hazard | A biological, chemical, or physical agent that can cause harm | |
| Herd immunity threshold | The proportion of immune animals above which an infection cannot keep spreading. The simple form is 1 − 1/R0 under homogeneous mixing. The vaccination coverage needed is higher when vaccine efficacy is below 100% | |
| Herd sensitivity | The probability that a testing protocol gives a positive herd result when the herd is infected at the design prevalence | Herd-level sensitivity |
| Import risk analysis (IRA) | A structured process to identify the hazards of an imported commodity, assess their risk, and choose measures to reduce it | |
| Incidence rate | The number of new cases divided by the animal-time at risk | Incidence density |
| Incidence risk | The proportion of animals at risk that develop the disease during a stated period | Incidence proportion, cumulative incidence |
| Incubation period | The time from infection to the first clinical signs | |
| Infectious period | The time during which an infected animal can transmit the agent | |
| Information bias | Bias that comes from errors in the measurement of exposure or outcome | Measurement bias, misclassification bias |
| Information need | An item of information that a decision requires, together with its possible source. Course convention | |
| Information-to-action loop | The cycle in which observation of a population gives information, information supports a decision, the decision leads to an intervention, and the intervention changes the population and the next observation. Course convention | |
| Interventional epidemiology | The approach that applies epidemiological evidence to choose measures that prevent and control health problems. Course convention | |
| Joint risk assessment | A risk assessment that the animal health, human health, and environment sectors carry out together, usually for a zoonosis | |
| Kappa | A measure of agreement between two tests or observers, beyond the agreement expected by chance | Cohen's kappa (mention once) |
| Latent period | The time from infection to the start of infectiousness | |
| Level of analysis | The level at which a problem is studied: the individual animal, the animal population, or the animal product and economic system. Course convention | |
| Line list | A table with one row per case and columns for key information (animal, place, time, signs, tests, exposures) | |
| Logistic regression | A regression model for an outcome with two categories that estimates the odds ratio of each factor while it accounts for the other factors | |
| Mantel-Haenszel odds ratio | An adjusted odds ratio that combines the odds ratios of several strata into one summary value | Pooled odds ratio |
| Monitoring | Repeated observation of a population without a defined link to action. Course convention | |
| Mortality rate | The number of deaths divided by the animal-time at risk | Death rate |
| Mortality risk | The proportion of animals at risk at the start of a period that die during the period | |
| Multivariable analysis | An analysis of one outcome with several factors at the same time | Multivariate analysis (for this meaning) |
| Natural history | The course of a disease in an animal from exposure to outcome, without intervention | |
| Negative predictive value | The probability that an animal with a negative test result is truly free of the condition | |
| Net benefit | The total benefits minus the total costs of an intervention | |
| Odds ratio | The odds of the outcome in exposed animals divided by the odds in unexposed animals. In a case-control study, the odds of exposure in cases divided by that in non-cases | |
| One Health | An approach that recognizes the links between the health of people, animals, and the environment, and works across sectors | |
| Opportunity cost | The value of the best alternative use of a resource | |
| Outbreak | The occurrence of cases above the expected level in a limited place and time, or a group of linked cases. More local than an epidemic | |
| Pandemic | An epidemic that spreads across several countries or continents | Panzootic |
| Parallel testing | Testing with two or more tests at the same time. An animal is positive if any test is positive | |
| Partial budget | A method that assesses a change on a farm by listing only the items that change: added revenue, reduced costs, added costs, and reduced revenue | |
| Passive surveillance | Surveillance that depends on reports from farmers, clinicians, or laboratories, without active selection of units | |
| Population | A defined group of animals that share a place or a production system, for example a herd, a flock, or all dogs in a district | |
| Population at risk | The animals that can develop the health event during the period of interest | |
| Population attributable fraction | The proportion of disease in the whole population that is due to the exposure, if the association is causal | |
| Population status | The state of a disease in a population, on a range from free to eliminated. The status points to an objective. Course convention | |
| Positive predictive value | The probability that an animal with a positive test result truly has the condition | |
| Precision | The degree to which repeated estimates agree. A narrow confidence interval shows high precision | Accuracy (for this meaning) |
| Predictive epidemiology | The approach that projects what could happen, through risk assessment and models. Course convention | |
| Prevalence | The proportion of animals in a population that have a condition at a point in time (point prevalence) or during a period (period prevalence) | Prevalence rate |
| Probability sampling | Selection in which every unit has a known chance, above zero, of selection | Random sampling (for the whole group of methods) |
| Problem frame | A short written statement of a population-level health problem with five parts: population, outcome, decision, decision maker, and objective. Course convention | |
| Public good | A good or service that benefits many people at the same time and from which it is hard to exclude anyone, for example freedom from an epidemic disease | |
| Reliability | The ability of a test to give the same result on repeated testing or between observers | |
| Risk | The likelihood that harm occurs and the size of its consequences. In measures of occurrence, a probability (see incidence risk) | |
| Risk difference | The incidence risk in exposed animals minus the incidence risk in unexposed animals | Attributable risk |
| Risk factor | A factor that is associated with an outcome and comes before it, so it can be used to predict or target. Course convention | |
| Risk ratio | The incidence risk in exposed animals divided by the incidence risk in unexposed animals | Relative risk |
| Risk-based surveillance | Surveillance that targets units with a higher probability of disease or higher consequences | Targeted surveillance |
| Sampling frame | The list or map of units from which a sample is drawn | |
| Scarcity | The condition in which resources (money, time, labour, vaccines, veterinary services) are not enough to meet all wants, so that choices are needed | |
| Selection bias | Bias that comes from the way units are selected into a study or a data source | |
| Sensitivity analysis | A check of how a result changes when the value of an input changes | |
| Sentinel surveillance | Surveillance in selected units (herds, sites, or animals) that are examined regularly | |
| Serial testing | Testing with a second test only the animals that are positive on the first test. An animal is positive only if all tests are positive | Sequential testing |
| Source population | The part of the target population from which study units can actually be selected | Accessible population |
| Specificity | The proportion of animals without the condition that test negative. Write "test specificity" when needed for clarity | |
| Sporadic | Describes a disease that occurs irregularly, in single cases or small groups | |
| Stratified analysis | An analysis that calculates a measure of association separately within levels (strata) of a third factor | |
| Study population | The units that are actually included in a study | |
| Surveillance | Systematic, ongoing collection, analysis, and communication of health data for a defined population and health event, with a defined link to action | |
| Target population | The population to which the results of a study or survey should apply | |
| Test sensitivity | The proportion of animals with the condition that test positive. Write "test sensitivity" when "sensitivity analysis" also appears | Sensitivity (when ambiguous) |
| True prevalence | The proportion of animals in a population that truly have the condition | |
| Unit of analysis | The unit used in a calculation or statistical analysis | |
| Unit of observation | The unit on which data are collected, for example one animal or one sample | Sampling unit (when it is the unit selected in sampling) |
| Validity | The degree to which a test measures what it should measure. For a diagnostic test: its sensitivity and specificity | Accuracy (for this meaning) |
| Veterinary economics | The application of economic principles to animal health and the use of scarce resources to protect it. Course convention | Animal health economics |
| Zoonosis | A disease or infection that is naturally transmitted between animals and people | |
