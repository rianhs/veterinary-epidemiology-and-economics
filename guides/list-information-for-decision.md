## Purpose

This guide shows you how to list the information that a decision needs. An [information need](../glossary.md) is one item of information that the decision requires, written together with a possible source for the item. The list starts from a problem frame and names each item once. You are done when each item could change the choice, each item has one possible source, and the decision maker has seen the list.

## When to use this procedure

Use this procedure when you have a problem frame and must decide what to find out. Write the list before you collect data or choose an analysis.

Do not use this procedure when the problem frame does not exist yet. Write the frame first with [Write a problem frame](write-problem-frame.md). Do not use this procedure to plan how to collect the data. The list says what you need and where it might come from, and a data plan is a later task.

## Procedure

The running example continues the layer farm district. The district has 60 layer farms, and one farm has Salmonella-positive hens. The owner of a small veterinary service company must decide whether to offer a paid testing and cleaning package. These numbers are synthetic and are for teaching.

### Step 1. Copy the problem frame

Write the problem frame at the top of the page. Check that it has the population, the outcome, the decision maker, the decision, and the objective.

Check: The frame has three sentences or fewer, and each of the five parts appears once.

Example: In the 60 layer farms of the district, one farm has Salmonella-positive hens and the number of positive farms is not known. The owner of a veterinary service company must decide whether to offer a paid testing and cleaning package to the 60 farms. The objective is to contain the problem and find its source.

### Step 2. List the options of the decision

Write each action that the decision maker can choose. Include the option to do nothing.

Check: The list has at least two options, and the decision maker accepts each one as possible.

Example: The options are a full package of testing and cleaning, a testing service only, and no service.

### Step 3. Ask what you need to know for each part of the frame

Take the five parts of the frame one at a time. For each part, write questions that information can answer. Write each question as one specific item, for example a count, a price, or a rule.

Check: Each part of the frame has at least one item.

Example: For the population, you ask how many farms and hens the district has. For the outcome, you ask how many of the 60 farms have positive hens. For the decision, you ask what each option costs and what farm owners would pay. For the decision maker, you ask which rules apply to testing and reporting. For the objective, you ask what the population status of Salmonella is.

### Step 4. Keep the items that could change the choice

Take each item in turn. Ask whether a different answer could lead the decision maker to choose another option. Remove the item if the answer is no.

Check: Every item left on the list could change the choice between the options.

Example: The share of positive farms stays, because a low share favours a testing service only, and a high share favours the full package. The history of how Salmonella was discovered goes, because it changes no choice.

### Step 5. Write one possible source for each item

Write where each item could come from. Choose a source type: existing records and documents, new data collection, or literature and expert advice. Prefer an existing source when it fits the item.

If an item has no possible source, write "no source known" and go to the interpretation of results.

Check: Each item has one possible source and one source type.

Example: The number of farms comes from the farm register of the district livestock service. The share of positive farms needs tests on a sample of farms, which is new data collection.

### Step 6. Write the final list and show it to the decision maker

Write the final list as a table with the columns item, part of the frame, possible source, and source type. Show the table to the decision maker. Add or remove each item that the decision maker corrects.

Check: The decision maker confirms that the list covers what is needed to choose.

Example:

| Item | Part of the frame | Possible source | Source type |
|-|-|-|-|
| Number of layer farms and hens | Population | Farm register of the district livestock service | Existing records |
| Share of the 60 farms with positive hens | Outcome | Tests on a sample of farms | New data collection |
| Cost of each option | Decision | Own accounts and the price list of the laboratory | Existing records |
| Price that farm owners would pay | Decision | A short survey of farm owners | New data collection |
| Rules for testing and reporting | Decision maker | The district livestock service | Existing documents |
| Effect of cleaning on positive results | Objective | Published studies and a poultry specialist | Literature and expert advice |

## Interpreting the results

The final list shows what you need to find out and where to look first. Start with the items that have existing sources, because they cost less and take less time.

If an item has no possible source, then ask whether another item can replace it. If no item can replace it, write the item as a gap and state the assumption that you will use.

If most items need new data collection, then compare the cost of each item with its value for the choice. Collect first the item that is most likely to change the choice.

If the list is longer than about ten items, then the frame may contain two decisions. Return to the frame and write one frame for each decision.

If the decision maker adds an item that cannot change the choice, then explain why. Offer a separate list for items that are only interesting.

## Common mistakes

The first mistake is to write a wish list. Items that are interesting but cannot change the choice make the list long and the work slow. Apply the test of Step 4 to every item.

The second mistake is to write an item without a source. A question with no place to look is not yet an information need. Write one possible source for each item, or mark the item as a gap.

The third mistake is to write vague items such as "data on Salmonella". A vague item gives no direction to the search. Write one specific count, price, rule, or effect for each item.

The fourth mistake is to list only epidemiological items. Many decisions also need costs, prices, and rules. Check each part of the frame, especially the decision and the decision maker, for items of this kind.
