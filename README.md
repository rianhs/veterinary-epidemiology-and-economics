# Veterinary Epidemiology and Economics

Teaching materials for the course Veterinary Epidemiology and Economics, Veterinary Medicine Study Program, Universitas Hasanuddin, Makassar, Indonesia.

The site is built with [Quarto](https://quarto.org) and published with GitHub Pages.

## Structure

| Folder | Content |
|-|-|
| `encyclopedia/` | Encyclopedia articles, one Markdown file per concept |
| `guides/` | Guides, one Markdown file per procedure |
| `slides/` | Interactive slide decks, one HTML file per deck |
